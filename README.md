# TaskWidget

A simple and effective task manager for Linux/Windows, written in C++ and Qt.

### Key Features:
- **Hierarchical Tasks:** Organize tasks in a tree view (Project -> Task -> Subtask).
- **Smart Alarms:** Scheduled notifications with visual indication (flashing window).
- **Plugin System:** Extend functionality via dynamic libraries (.so/.dll).
- **VS Code Integration:** VS Code Integration: Quickly open a project folder directly from the widget.

### Technology Stack:
- C++17
- Qt 5.15+ (Widgets, Network)
- CMake / qmake
- nlohmann/json (for data storage)
